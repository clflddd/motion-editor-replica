# Editor Replica — Remotion 动效复刻

用 [Remotion](https://www.remotion.dev/) 复刻的一段「插画风视频剪辑器」30 秒动效短片。画面、角色、界面与时间轴全部由 React + SVG 手绘实现，不依赖任何位图素材，仓库自包含。

## 效果概览

1280×720 / 30fps / 900 帧（30s），与参考录屏同规格。

分镜节奏：

| 时间 | 内容 |
| --- | --- |
| 0–1.5s | 米色画布上弹出代码窗口，逐字敲出 `const 剪辑软件 = 小克.写代码()` |
| 1.5–3s | 编辑器界面弹入：标题栏、素材/转场/文字面板、竖屏预览、调整面板、时间轴 |
| 3–6s | 橙色小方块「小克」把月夜 / 拉面 / 柴犬 / 小克跑步拖进时间轴，预览开始播放 |
| 6–8s | 对焦动画、废片斜线区、垃圾桶「哐当！」删除片段 |
| 8–12s | 切到「转场」面板，溶解转场把画面带到柴犬 |
| 12–17s | 「文字」面板加入「前方高能预警」，Ctrl+Z 撤销、绿色「已修正」印章 |
| 16–20s | 小克伸出长手把饱和度拉到 150%，「饱和度：拉满 / 爆表!!」 |
| 20–24s | 音频轨逐颗落下的黄色三角卡点标记 +「卡点」按钮 |
| 24–28s | 导出按钮变成「渲染中 99.99%」，小克长手指向导出 |
| 28–30s | 编辑器压暗，手写便签「30 秒剪完，Opus 5.5 — 小克 收工」 |

## 运行

```bash
npm install
npm run dev      # 打开 Remotion Studio 实时预览
```

## 渲染

```bash
npm run render   # 输出 out/editor-replica.mp4
npm run still    # 输出 out/still.png（默认第 0 帧）
```

渲染指定帧：

```bash
npx remotion still src/index.ts EditorReplica out/frame-500.png --frame=500
```

## 目录结构

```
src/
├── index.ts          # registerRoot
├── Root.tsx          # Composition：900 帧 / 30fps / 1280×720
├── theme.ts          # 调色板、字体、缓动、时间轴几何常量
├── scenes.tsx        # 月夜 / 拉面 / 柴犬 / 霓虹小克 四组 SVG 画面 + 手机壳
├── ui.tsx            # 面板、贴纸、手写箭头、吉祥物、标题栏
├── panels.tsx        # 左侧素材/转场/文字面板、右侧调整滑杆
├── timeline.tsx      # 刻度、片段、斜线废片、波形、卡点标记、垃圾桶、播放头
├── intro.tsx         # 开场代码窗口、结尾手写便签
└── EditorReplica.tsx # 主时间线编排与全部手写标注
```

## 技术要点

- 所有角色和界面均为 SVG / DOM 绘制，保证可无限缩放且无版权素材。
- 缓动统一封装在 `theme.ts`：`p()` 为贝塞尔淡入，`sp()` 为弹簧，标注用 `popIn()` 做回弹。
- 时间轴几何集中在 `TL` 常量里，片段位置按「秒 × 像素/秒」计算，便于调整节奏。
- 相机只做极轻微推近，避免裁切；结尾用压暗层 + 便签完成收束。
